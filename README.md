# 🛒 বাজার দর | BazarDor

### Know Your Market, Make Smarter Choices.

**BazarDor** is a modern, user-friendly web application designed to help people explore the prices of everyday commodities in Bangladesh. It provides an organized platform where users can browse products by category, check market prices, and identify price changes through visual indicators.

The project aims to make market price information easier to access through a clean interface, responsive design, and convenient navigation. BazarDor combines modern web technologies to deliver a smooth and accessible experience across different devices.

## 🌐 Live Demo

🔗 **Live Website:** https://bazar-dor-sigma.vercel.app/

## ✨ Key Features

- **📊 Market Price Updates:** Explore the prices of everyday commodities in one place and make informed purchasing decisions.
- **📂 Category-Based Browsing:** Discover products through organized categories for a simple and convenient browsing experience.
- **📈 Price Trend Indicators:** Quickly identify price increases and decreases with clear visual indicators.
- **🔐 User Authentication:** Create an account, sign in, and access personalized account features with Better Auth.
- **📱 Fully Responsive Design:** Enjoy a consistent and user-friendly experience across mobile phones, tablets, laptops, and desktop devices.

## 🛠️ Technologies Used

The project is built using modern web technologies to ensure maintainability, performance, and a responsive user experience.

| Technology       | Purpose                                                 |
| ---------------- | ------------------------------------------------------- |
| **Next.js**      | React framework for application development and routing |
| **React.js**     | Building reusable and interactive UI components         |
| **TypeScript**   | Type safety and improved code maintainability           |
| **Tailwind CSS** | Responsive styling and modern UI design                 |
| **HeroUI**       | Reusable UI components and interface elements           |
| **Better Auth**  | User authentication and account management              |
| **Lucide React** | Clean and consistent icons                              |
| **REST API**     | Fetching and displaying product and market price data   |
| **Vercel**       | Application deployment and hosting                      |

## 📱 User Experience

BazarDor focuses on simplicity and usability. Its green-themed interface creates a consistent visual identity, while category navigation and price indicators help users find relevant information quickly.

The responsive layout adapts to different screen sizes, making the application convenient to use on both mobile and desktop devices.
